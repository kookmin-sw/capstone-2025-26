# 회고 함 해볼래? - To-Go

## 1. 프로젝트 소개 
회고란 지나간 일을 돌이켜 보며 성찰하고 배우는 과정을 말합니다. 더 나은 자신 혹은 더 나은 크루가 되기 위해 과거를 분석하고 개선점을 찾는 것을 목표로 두고 있습니다. 

KPT, 4L, PMI 등 다양한 회고 방식이 있지만 혼자 하기에는 부담스럽고 회고가 습관화 되기에는 더욱 어렵습니다. 저희는 크루 기능을 통해 같은 목표를 가지고 있는 사람들이 모여 회고하고 서로의 피드백을 주고받음을 통해 회고의 습관을 들일 수 있도록 하고 목표의 달성 확률을 높여줍니다.

크루를 만들어 회고를 하지만, 결국 회고는 혼자 작성해야 합니다. 그 과정 저희 회고 Agent가 도와주겠습니다!
- 챌린지를 세우고 플랜을 세우기 어려우시다고요? 저희 회고 Agent는 챌린지를 기반으로 플랜과 KPI를 산정해 줍니다.
- 매일 회고한 내용을 정량적으로 분석하기 어려우시다고요? 저희 회고 Agent는 오늘 회고한 내용을 분석하고 점수를 부여해 줍니다.
- 이번주 회고한 내용을 종합해 판단하기 어려우시다고요? 저희 회고 Agent는 이번 주 회고한 내용을 분석해 주간 리포트를 작성해 줍니다.


저희 To-Go와 함께 멋진 챌린지를 만들고 회고하며 달성해 봐요!

## 5. 설치 및 실행
frontend
- 에뮬레이터 실행
```
flutter devices
flutter emulators --launch [deviceName]
```
- 실제 프로젝트 실행
```
git clone https://github.com/kookmin-sw/capstone-2025-26.git
cd frontend
flutter pub get
flutter run
```
backend
```
git clone https://github.com/kookmin-sw/capstone-2025-26.git
cd journey
sudo docker compose up
```
